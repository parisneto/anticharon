# Release Manifest: Anticharon v0.7.0

**Sprint:** Effective History & Model Identity  
**Release Tag:** `v0.7.0`  
**Date:** 2026-10-08  

---

## 1. Executive Summary

One price per model, on one definition, for the live quote, the stored history and the alerts.

1. **Standard-tier price (AC-8):** the cheapest standard-tier endpoint, blended with the calibration. Visible effect with default weights: `openai/gpt-5.6-luna` 0.03265 → 0.06529 and `google/gemini-3.1-flash-lite` 0.04081 → 0.08162.
2. **History from listed prices (AC-9):** time-weighted daily mean of the cheapest standard listed price, blended with the calibration; OpenRouter's effective price is no longer used.
3. **Observed-vs-observed alerts:** `PRICE_SPIKE` / `PRICE_DROP` compare the latest observation with the 7-day observed average; the live quote never raises one.
4. **Analytics by observed days (AC-1, AC-3), Hermes sync fixes (AC-2), redirect identity (AC-4), `effective_prices.json` MCP resource (AC-5), discovery without `:batch` (AC-6), one help contract (AC-7).**
5. **Update tool:** `install_only` is the default and the only advertised type; `restart_host`, `phoenix`, `reload_request` are deprecated and planned for removal in 0.8.0.

Details: [CHANGELOG.md](../../CHANGELOG.md), [spec](../specs/spec_v1_anticharon.md), [execution contract](../plans/effective-history-model-identity/EXECUTION_CONTRACT.md).

## 2. Upgrade

```bash
uv tool install --force git+https://github.com/parisneto/anticharon.git@v0.7.0
anticharon run --force
```

Or use the self-update (experimental): `anticharon check-updates`, then `anticharon update --type install_only`; MCP hosts call `run_update()` and then reload the server (Hermes: `/reload-mcp`). `update` reinstalls from the default branch without comparing versions.
