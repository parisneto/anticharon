## 1. Executive Summary

Anticharon `v0.6.0 Beta` marks a major leap in autonomous agent ergonomics, predictability, and discoverability. Built across a 7-wave architecture governed by an immutable execution contract (`EXECUTION_CONTRACT.md`), this release unifies agent messaging, establishes deterministic local/remote command boundaries, expands the MCP tool surface from 4 to 13 tools with standard MCP-9 annotations, introduces empirical token-weight calibration, and implements failover cost impact alerting.

---

## 2. Issues Delivered & Traced

This release completes and resolves 12 tracked GitHub issues:

- **#12 (W1 Foundation):** Unified agent message contract (`messages` envelope, `status` mapping, `elapsed_ms`, MCP `isError: true` / CLI exit 1).
- **#13 (W3 Command Split):** Clean separation of local read commands (`check`, `history`) and network fetch-and-persist (`run` / `run_prices`), with persistent `alerts.json`.
- **#14 (W2 Model Identity):** Source-tagged shortlist management, explicit Hermes ordering, and declared default model integrity.
- **#15 (W2 Model Identity):** Strict exact-match model slug enforcement with zero silent substitutions or drops (D-14/18c).
- **#16 (W4 Tool Surface):** CLI/MCP parity tools (`add_model`, `remove_model`, `list_models`, `self_test`, `calibrate_token_weights`).
- **#17 (W4 Tool Surface):** Full MCP-9 annotations on all registered tools (`readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint`).
- **#18 (W4 Tool Surface):** Prompt parity across CLI (`anticharon prompt`) and MCP server, with authoritative glossary links.
- **#19 (W6 Fallback Alerts):** Hermes fallback-aware alerts (`NEXT_FALLBACK_PRICE`, `NEXT_FALLBACK_UNAVAILABLE`) comparing default model failover costs.
- **#20 (W5 Host Integrations):** Experimental self-update mechanism (`check_updates` / `run_update`) with SemVer tuple parsing and 2-second GitHub timeout.
- **#21 (W7 Docs & Release):** Single authoritative `llms.txt` packaged in the wheel, sanitized installation paths, and agent skill definition.
- **#22 (W1 Governance):** Pinned protocol baseline rule (MCP specification `2026-07-28`) and pre-work cleanup.
- **#23 (W7 Release):** Manual release verification gates (MG-1, MG-2, MG-3) and host sign-off.
